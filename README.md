# Gold Price Calculator

**Live site:** https://a7med-itw.github.io/gold-calculator/

A small web app for checking a jeweller's gold price against the live rate published by Nizwa Royal Jewellery. The interface is in Arabic and works on phone and desktop.

## What it does

- Loads the current gold price automatically when opened
- Shows the price per gram for 24K, 22K, 21K and 18K, plus per tola and per ounce
- Splits a seller's quoted price into gold value and making charge, and flags anything above the expected range
- Covers gold bars with common fixed weights (grams, tola, ounces)
- Can be added to the iPhone home screen and opens like an app

## Note

Prices are for reference only. They follow the rate shown on nizwaroyaljewellery.com, and the final price is confirmed in store.
